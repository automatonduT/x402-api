Batch x402 Inspector

Paste up to 5 endpoint URLs (one per line or comma-separated). Free, no key, no signup. Each URL gets probed live and classified:

  • PAYABLE — proper 402 with an accepts block standard libs can use
  • 402_SANS_ACCEPTS — charges money but agents cannot parse how to pay
  • FREE_OR_OPEN — no payment required
  • HTTP_0 — unreachable / timeout

Machine API: GET /tools/x402/batch-inspect?urls=a,b,c
