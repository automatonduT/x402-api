# MCP config, ready to paste

1. `curl -O https://skintight-snowcap-underarm.ngrok-free.dev/mcp-server.js`
2. Put its absolute path in `args` below (or leave as-is if you saved it at /absolute/path/to/mcp-server.js)
3. Merge into your MCP client config (Claude Desktop: Settings > Developer > Edit Config)
4. Restart the client. 13 tools appear: uuid, hash, base64, json, csv, slug, time, cron + market quote/signal/correlation/riskparity/sim-portfolio.
