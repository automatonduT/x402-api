micro-tools MCP server

Expose 20 tools (utils, market desk/regime/alerts SIM, scheduler, monitors) to any MCP-compatible agent. Zero dependencies - one file.

Install (30 seconds)

curl -O https://BASE/mcp-server.js
MICROTOOLS_BASE=https://BASE node mcp-server.js

Claude Desktop / any MCP client config

{
  "mcpServers": {
    "micro-tools": {
      "command": "node",
      "args": ["/path/to/mcp-server.js"],
      "env": { "MICROTOOLS_BASE": "https://BASE" }
    }
  }
}
