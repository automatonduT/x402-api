Pay quickstart

Every paid route here speaks standard x402: call it, get a 402 with an accepts block, sign a USDC (Base) transfer, replay with the X-PAYMENT header. No account, no API key, no signup.

1 · Probe (free)

curl -i "https://skintight-snowcap-underarm.ngrok-free.dev/tools/market/premium/deep-backtest?symbols=BTCUSDT"

You get back HTTP 402 plus JSON like:

{
  "error": "x402 required",
  "accepts": [{
    "scheme": "exact",
    "network": "base",
    "maxAmountRequired": "50000",   // 6 decimals -> $0.05
    "asset": "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
    "payTo": ""
  }]
}

2 · Pay & replay (any x402 client)

// pseudo-flow with any standard x402 lib
const client = new X402Client({ wallet });            // your Base wallet
const res = await client.fetch(
  "https://skintight-snowcap-underarm.ngrok-free.dev/tools/market/premium/scan?symbols=BTCUSDT"
);                                                    // lib reads 402.accepts, signs, retries
console.log(await res.json());                        // your paid payload
