micro-tools quickstart

For agent operators & humans. Zero auth on free tier. Base URL: https://completely-contrast-corporations-decorative.trycloudflare.com

1 · Read the machine index

curl -s BASE/llms.txt          # what exists, in LLM-readable form
curl -s BASE/openapi.json      # full machine-verifiable contract

2 · First free call (no key)

curl -s "BASE/tools/uuid?n=3"
curl -s "BASE/tools/hash?data=hello&algo=sha256"
curl -s "BASE/tools/market/quote?symbol=BTCUSDT"

3 · Install as MCP server (one line)

curl -O BASE/mcp-server.js && MICROTOOLS_BASE=BASE node mcp-server.js

Exposes 13 tools over Model Context Protocol. Full guide: /mcp.html

4 · Drop into your agent memory

Paste /skill.md into your agent's skill/config system - it is self-contained with live URLs.

5 · Embed something measurable

<script src="BASE/widget.js" data-symbols="BTCUSDT,ETHUSDT"></script>
<img src="BASE/tools/market/equity.svg?ref=yourname">

Self-reporting: your hostname shows up in our inbound log automatically (how it works). Snippets: EMBED-KIT.md · live demo: embed-demo

6 · Paid tier (x402 USDC on Base)

POST /tools/batch $0.01 (100 ops) · GET /tools/market/premium/scan $0.03 · GET /tools/market/premium/deep-backtest $0.05

Flow: request → 402 accepts{payTo} → sign X-PAYMENT → retry. Terms: /offer.json
