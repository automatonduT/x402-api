strategy-check: la demo qui dit NON

Voici un exemple reel produit par le moteur de POST /tools/strategy-check. Serie synthetique 120 barres: tendance haussiere puis regime baissier. Les stats TRAIN sont flatteuses (+WR eleve). Le moteur REFUSE quand meme:

{
  "decision": "REFUSE",
  "reasons": [
    "trades OOS insuffisants",
    "pnl OOS negatif (-0.33)"
  ],
  "best": {
    "params": {
      "fast": 5,
      "slow": 20,
      "sl": 0.03,
      "tp": 0.06
    },
    "train": {
      "trades": 1,
      "pnl": 0.83,
      "winRate": 100
    },
    "test": {
      "trades": 1,
      "pnl": -0.33,
      "winRate": 0
    },
    "gap": 1.16
  }
}

Pourquoi cest la valeur: la plupart des backtests montrent le train. Celui-ci valide hors echantillon et refuse si le gap train/test trahit un overfit.
